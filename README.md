# PLE Engineering Agent Harness

**Project:** Research, implement and rigorously evaluate a single engineering AI agent harness on Google's Physical-Engineering's Last Exam (PLE).

**Maintainer:** Dossiya Dakou  
**State:** Google's runnable minimal starter is included as the **baseline**. Development evaluations, ablations, multi-model comparisons and costs have **not yet been measured**. No submission or leaderboard result is claimed.

## Research objective

Build a general-purpose AI harness that transforms engineering requirements and source documents into **physically feasible, computationally checked, constraint-compliant and reproducible engineering deliverables** across multiple disciplines.

## Benchmark and evaluation

Google's PLE comprises **85** tasks: **29 public development** tasks (9 electrical, 7 mechanical, 9 civil, 4 structural) and **56 hidden** tasks. Each public task has a six-hour limit. The dev score is the mean of the 29 normalized task scores (0 to 1); any unmeasured task contributes 0.

The benchmark's public grading methods are programmatic checks, AI rubric judgments and mixed checks/judgment. No source task files have been committed here: the official [Hugging Face dataset](https://huggingface.co/datasets/google/physical-engineerings-last-exam) is gated.

## Baseline harness

`serve.py`, `taskbridge.py`, `requirements.txt`, and `submission.yaml` reproduce Google's Apache-2.0-licensed **minimal** sample at source commit [`8320f0402fdca9f42476607f72bcfd5271cd50c9`](https://github.com/google-research/ple/commit/8320f0402fdca9f42476607f72bcfd5271cd50c9). It is intentionally a baseline, not an improved multi-tool harness. The sample supports shell/file operations, a model tool loop, deadline wrap-up and basic API retry/compaction. It **does not support task MCP tools**, which limits some assignments. See [attribution](THIRD_PARTY_NOTICES.md).

To prepare an eligible advanced harness, add MCP tool discovery, requirements extraction, deterministic calculation/checking, evidence-preserving context management, robust fault recovery, and deliverable validation. These are planned, **not falsely marked implemented**.

## Local setup

Install [Docker](https://docs.docker.com/engine/install/), [uv](https://docs.astral.sh/uv/), and Harbor. Get approval for the [gated dataset](https://huggingface.co/datasets/google/physical-engineerings-last-exam), configure a compatible Google-sponsored model and judge, and follow [model instructions](https://github.com/google-research/ple/blob/main/docs/models.md). Never commit `HF_TOKEN`, model credentials or `local.env`.

```bash
git clone https://github.com/google-research/ple.git
git clone https://github.com/Dossiya-SE/PLE-Engineering.git
cd ple
uv tool install harbor==0.20.0 --with websockets
# After configuring your model gateway and HF dataset access:
uv run python -m kit check ../PLE-Engineering
uv run python eval/run.py ../PLE-Engineering --tasks lv-cable-sizing
uv run python eval/run.py ../PLE-Engineering
uv run python -m kit artifacts ../PLE-Engineering
uv run python eval/run.py --artifacts ../PLE-Engineering
```

These commands have **not** been executed in this repository. The public evaluation environment may need a substantial Docker installation and a paid model gateway. Before running, confirm the current official kit's requirements.

## Experimental results

Until actual runs exist, `results/` contains **only templates and explicit pending status**. `scripts/analyze_scores.py` can analyze a carefully normalized CSV of real run results. It fails on unsupported or missing values rather than inventing observations. Offline tests run with:

```bash
python -m unittest discover -s tests -v
```

## Competition integrity

The harness must not access public grading code, hard-code task answers, branch on task IDs, access unauthorized external APIs, or read committed prior artifacts at runtime. Submitted `artifacts/` must be generated by `eval/run.py` from this exact harness and declared sponsored model. See [official rules](https://github.com/google-research/ple/blob/main/docs/rules.md).
